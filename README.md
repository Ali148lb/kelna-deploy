# كلنا لبعض — الرفع على Render (الخطة المجانية)
الخطة المجانية تمسح الملفات عند كل إعادة تشغيل، لذلك الموقع يحفظ قاعدة البيانات تلقائيًا في تخزين مجاني خارجي (S3) ويستعيدها عند التشغيل.

## 1) تخزين النسخة الاحتياطية (مرة واحدة) — Backblaze B2
1. أنشئ حسابًا في backblaze.com ← B2 Cloud Storage ← Buckets ← Create a Bucket (اجعله **Private**).
2. من تفاصيل الـBucket انسخ **Endpoint** (مثل `s3.us-west-004.backblazeb2.com`) — المنطقة هي الجزء `us-west-004`.
3. Application Keys ← Add a New Application Key ← اقصرها على هذا الـBucket ← انسخ `keyID` و`applicationKey` (يظهران مرة واحدة).
(يعمل أيضًا أي S3 مثل Cloudflare R2 بنفس المتغيرات.)

## 2) GitHub ثم Render
ارفع محتويات المجلد إلى GitHub ← Render: New + ← Blueprint ← المستودع. اكتب القيم:
- `ADMIN_EMAIL`, `ADMIN_PASSWORD`
- `S3_ENDPOINT` = `https://s3.us-west-004.backblazeb2.com` (بحسب منطقتك)
- `S3_REGION` = `us-west-004`
- `S3_BUCKET` = اسم الـBucket
- `S3_KEY_ID`, `S3_SECRET`

## 3) الدخول
`الرابط/#/admin-login`
